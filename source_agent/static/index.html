    Quality policy

    Shared by local validation, BigQuery analysis and generated Spark code.

    CONFIGURABLE

    High-runner detection

    Quarantine rows associated with an identifier whose distinct fanout exceeds the limit.

    Example: device_os = “iPad” becomes “ipados”. A device_type of “mobile” is a conflict. Repair mode changes it to “tablet”; ambiguous conflicts stay quarantined.

    Canonical schema mapping

    Auto-detected from common aliases. Override to match your source.
